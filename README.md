# Asisten Hukum LBH Jalapaksi (PWA)
PWA wajib dibuka lewat alamat https. Cara termudah: GitHub Pages.
1. Buat repo GitHub (Public), upload SEMUA isi folder ini (index.html, manifest.json, sw.js, folder icons).
2. Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder /(root) > Save.
3. Tunggu 1-2 menit, buka https://NAMAANDA.github.io/NAMAREPO/
4. Android (Chrome): menu titik tiga > "Instal aplikasi" / "Tambahkan ke layar utama".
   iPhone (Safari): Bagikan > "Tambah ke Layar Utama". Desktop (Chrome/Edge): ikon instal di address bar.
Alternatif: drag-drop folder ke netlify.com/drop.
